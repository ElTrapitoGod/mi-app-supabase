## Descripción del proyecto

Este proyecto permite registrar estudiantes en la tabla estudiantes de una base de datos en Supabase. Para agregar un registro, el usuario inicia sesión y captura el nombre y la carrera en el formulario. Al enviarlo, el código inserta esos datos en la base de datos y los muestra en la tabla de la aplicación. El campo id se genera automáticamente en Supabase.
